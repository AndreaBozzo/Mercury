# Support

Mercury is maintained on a best-effort basis as an early research project.

Use a GitHub issue for reproducible defects, documentation errors, and narrowly scoped feature
proposals. Include the Mercury and Nephtys revisions, operating system, Python version, deployment
mode, relevant configuration with secrets removed, expected behavior, actual behavior, and the
smallest useful log excerpt.

Follow [SECURITY.md](SECURITY.md) instead for vulnerabilities, credentials, private infrastructure,
or conduct reports.

The project does not provide:

- financial, investment, legal, tax, or regulatory advice;
- confirmation that a venue or product is available to a particular person or jurisdiction;
- exchange account support;
- strategy profitability guarantees;
- live-capital deployment support or incident response.

The supported alpha path is the public observation pipeline documented in the README. Sandbox,
Bytewax, and legacy Binance paths are experimental and may receive lower-priority support.
